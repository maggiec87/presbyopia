# Presbyopia

预防老花眼

## 项目简介

这个项目并不是一个“介绍老花眼知识”的展示型网页，而是一个在线练习页面，用来训练和提升人眼在近距离和远距离之间的调节能力，帮助预防老花眼。

它的核心目标是：让用户通过反复切换“远处”和“近处”观察目标，锻炼眼睛的调节功能，提升对近距离物体和远距离物体的快速切换能力。

## 这是什么类型的项目

本仓库的实际用途更接近于：

- 近远距离调节能力训练工具
- 视力保健/老花眼预防练习页面
- 一个针对“看近”和“看远”切换训练的交互式网页

它不是单纯的健康科普站点，而是一个可以直接使用的在线练习工具。

## 功能特点

- 提供近距离和远距离目标切换练习
- 训练眼睛在看近和看远之间的快速调节
- 适合日常时间较短的视力保健训练
- 纯 HTML/静态网页实现，便于本地使用和部署
- 适合用作静态网站、练习页面或教学演示

## 本地运行

因为这是一个静态网页项目，您可以直接在浏览器中打开 `index.html` 进行预览，或者使用本地服务器：

```bash
python -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000
```

## 使用说明

这个项目的核心是“远近距离调节训练”。

在使用时，通常会让用户按固定节奏在以下两种状态之间切换：

- 远距离观察：看远处的目标
- 近距离观察：看近处的目标

通过反复训练，可以帮助提升眼睛在不同距离之间的调节灵活性，进而有助于预防老花眼相关问题。

## 注意事项

- 请在光线适中的环境中使用
- 训练时保持舒适姿势，避免疲劳
- 若出现明显视疲劳、头晕或视力变化，请停止并及时咨询专业医生
- 本项目仅用于辅助训练，不替代正规医学检查或治疗
